# Excel Modules 26

A structured collection of Microsoft Excel learning materials and hands-on practice exercises covering essential spreadsheet concepts, formulas, and data formatting techniques.

This repository documents my Excel learning journey through practical exercises designed to strengthen my spreadsheet skills and build a foundation for data analysis.

## 📚 Topics Covered

### 1. Excel References
Learn how cell references work and how they are used in formulas to perform calculations efficiently.

**Topics include:**
- Relative cell references
- Absolute cell references
- Mixed cell references
- Using `$` to lock rows and columns
- Applying cell references in formulas

### 2. Excel Loop Functions
Explore repetitive calculations and formula-based techniques to work with data efficiently.

**Topics include:**
- Understanding repetitive calculations
- Applying functions across datasets
- Using logical conditions in calculations
- Practicing formula-based operations

### 3. Conditional Formatting
Learn how to highlight important information and identify patterns in data using formatting rules.

**Topics include:**
- Highlight Cells Rules
- Greater Than / Less Than conditions
- Duplicate and Unique Values
- Data Bars
- Color Scales
- Icon Sets
- Formula-based conditional formatting
